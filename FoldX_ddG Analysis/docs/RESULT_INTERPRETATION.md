# Result Interpretation

The FoldX sign convention used in this repository is:

```text
ΔΔG = ΔG_mutant − ΔG_wild type
```

- Negative ΔΔG: predicted stabilization.
- Positive ΔΔG: predicted destabilization.

The default exploratory classification uses a neutral interval of ±0.5 kcal/mol. This is a post-processing choice and is not an official FoldX calculation threshold.

# Reproducibility Statement

All scripts, mutation definitions, FoldX command-line parameters, raw output files, and processed ΔΔG tables associated with the 22 independent single-point mutation calculations have been deposited in a public GitHub repository. Each mutation was modeled in three FoldX runs. The repository contains automated scripts for structure repair, mutation modeling, result collection, and calculation of the mean, standard deviation, minimum, and maximum ΔΔG values.

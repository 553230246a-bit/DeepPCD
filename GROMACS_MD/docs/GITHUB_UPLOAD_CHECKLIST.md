# GitHub Upload Checklist

- [ ] Add the exact protein PDB used in the simulation.
- [ ] Add the exact ligand MOL2 and ACPYPE output files.
- [ ] Add the final assembled `complex.gro`.
- [ ] Add the final `topol.top` and every included ITP file.
- [ ] Add exact `ions.mdp`, `em.mdp`, `nvt.mdp`, `npt.mdp`, and `md.mdp`.
- [ ] Add the exact index files and document interactive group selections.
- [ ] Add GROMACS `--version` output.
- [ ] Add GPU, driver, CPU, and operating-system metadata.
- [ ] Add all `grompp` and `mdrun` logs.
- [ ] Add energy-minimization, NVT, NPT, and production quality-control data.
- [ ] Add processed RMSD, RMSF, Rg, hydrogen-bond, SASA, and distance data.
- [ ] Add MM/PBSA parameter files and tool versions when MM/PBSA is reported.

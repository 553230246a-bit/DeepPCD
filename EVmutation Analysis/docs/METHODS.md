# Manuscript-Ready Methods

The evolutionary compatibility of 22 independent amino-acid substitutions in BhNIT was evaluated using EVmutation as implemented through EVcouplings and plmc under Windows Subsystem for Linux (Ubuntu 24.04). The complete BhNIT amino-acid sequence was used as the query in five iterations of jackhmmer against UniRef90. Sequence- and domain-level reporting and inclusion E-value thresholds were set to 1 × 10⁻³, and the HMMER random seed was fixed at 42. The resulting alignment was centered on the BhNIT focus sequence, and homologous sequences covering at least 70% of the 338-residue target sequence were retained. The final focus alignment contained 53,836 sequences and 338 target positions.

A pairwise Potts model was inferred using plmc compiled in single-precision OpenMP mode. BhNIT was specified as the focus sequence, gaps were excluded from potential calculations, the sequence-reweighting divergence threshold was set to 0.2, L2 regularization parameters were set to 16.0 and 0.01 for pairwise couplings and single-site fields, respectively, and the maximum number of optimization iterations was set to 100.

All 22 wild-type residues were validated against the focus sequence encoded in the model before mutation scoring. Mutation effects were calculated using `CouplingsModel.delta_hamiltonian`. The full epistatic ΔE, pairwise-coupling contribution, single-site field contribution, and independent-site ΔE were recorded for each substitution. EVmutation scores are dimensionless evolutionary statistical-energy differences relative to BhNIT; they are not thermodynamic ΔΔG values and were not converted to kcal/mol. No universal absolute cutoff was applied, and variants were ranked within the BhNIT-specific model.
